This lab walks through the integration and deployment operations required to run a given Backstage application that display metrics data collected from Prometheus.

## Learning objectives

The objective of this lab is to learn how to:

1. Add the Prometheus plugin to an existing Backstage application
2. Configure the Prometheus plugin
3. Add Prometheus rules to retreive metrics data of an application component
