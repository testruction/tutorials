This lab walks through the publication of technical documentation (docs-as-code) with **TechDocs**, in a Backstage application built on the [new frontend system](https://backstage.io/docs/frontend-system/).

TechDocs builds Markdown files stored next to the source code with [MkDocs](https://www.mkdocs.org/), then renders the result in the Backstage UI, in the **Docs** tab of each catalog entity.

## Learning objectives

The objective of this lab is to learn how to:

1. Check that the TechDocs plugins are enabled in a new Backstage application
2. Configure the TechDocs builder, generator and publisher
3. Write the documentation of a catalog component with MkDocs
4. Browse the documentation from the Backstage UI
