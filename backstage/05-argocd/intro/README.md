This lab walks through the integration and deployment operations required to run a given Backstage application that collects deployment states from Argo CD.

## Learning objectives

The objective of this lab is to learn how to:

1. Add the Argo CD plugin to an existing Backstage application
2. Configure the ArgoCD plugin
3. Add annotation to the service catalog to retreive deployment data of related to application components
