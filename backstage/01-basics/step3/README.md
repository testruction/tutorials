# Access the Backstage UI

Run the following application in development mode.

```bash
yarn start
```{{exec}}

[Click here]({{TRAFFIC_HOST1_3000}})  to open the Web console.

> **Notice**:
> The command starts the frontend and the backend in a single process (`backstage-cli repo start`). The legacy `yarn dev` script no longer exists.
> The application uses the guest authentication provider, so click on **Enter** on the sign-in page.
