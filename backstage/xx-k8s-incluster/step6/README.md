# Build the Backstage production-ready container

> Notice:
>The container uses the `app-config.production.yaml` file which leverage PostgreSQL instead of the in-memory SQLite database engine.

Build the backstage application.

```bash
yarn build:backend
```{{exec}}

> **Notice**:
> The `packages/backend/Dockerfile` generated by Backstage already uses a Node.js 24 base image (`node:24-trixie-slim`), the same major version as the host. No change is required.

Build the container image.

```bash
docker image build . -f packages/backend/Dockerfile --tag backstage:1.0.0
```{{exec}}

Archive the generated image.

```bash
docker save --output ~/backstage-v1.0.0.tar backstage:1.0.0
```{{exec}}

Import the image archive into the Containerd runtime.

```bash
sudo ctr images import ~/backstage-v1.0.0.tar \
&& rm -vf ~/backstage-v1.0.0.tar
```{{exec}}
