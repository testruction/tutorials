# Check the Kubernetes backend plugin

The Backstage application template generated by `@backstage/create-app` already includes the Kubernetes backend plugin.
Backstage uses the [new backend system](https://backstage.io/docs/backend-system/): each plugin is a module registered with `backend.add()`, so no plugin router or `PluginEnvironment` boilerplate is required.

Verify that the `@backstage/plugin-kubernetes-backend` package is registered in `packages/backend/src/index.ts`.

```bash
grep -n "plugin-kubernetes-backend" packages/backend/package.json packages/backend/src/index.ts
```{{exec}}

> **Notice**:
> On an application that does not include the plugin yet, install it, then register it in the backend.
>
> ```bash
> yarn --cwd packages/backend add @backstage/plugin-kubernetes-backend
> ```
>
> ```typescript
> // packages/backend/src/index.ts
> backend.add(import('@backstage/plugin-kubernetes-backend'));
> ```
