## Sandbox0


Operation | Script
--------- | ------
Create local users and groups | `./write-users.sh`
Install OpenSSH | `./install-ssh.sh`
Install LXD | `./install-ssh.sh && ./install-lxd.sh`
Create loopback ISCSI drives (default: 16*512MB) | `./install-iscsi.sh 8`
Generate files with random name, attributes and permissions | `./write-files.sh`
