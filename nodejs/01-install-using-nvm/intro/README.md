## Install Node using Node Version Manager (NVM)

This lab walks through the installation of the Node.JS runtime using the recommanded approach that leverages Node Version Manager (NVM).

NVM is recommanded because it allows to install multiple version of the `node` runtime, while not requiring superuser privilege on the developer workstation.

### Learning objectives

The objective of this module is to learn how to:

- Install NVM
- Install multiple version of the `node` runtime
- Select a specific version to start to develop with
