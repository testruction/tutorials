# Beep Bop _(Exercise 1 of 17)_

Create the workshop directory where allow exercices will be performed.

```sh
mkdir stream-adventure && cd stream-adventure/
```{{exec}}

Create a new file called beep_boop.js that uses console.log to output "beep boop".

To verify your program has the expected output, run:

```sh
stream-adventure verify beep_boop.js
```{{exec}}

for more options, run `stream-adventure help`.
