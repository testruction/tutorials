# Backstage

This lab walks though the various operations required to configure and run a local Backstage development environment.

## Learning objectives

The objective of this lab is to learn how to:

1. Create a Backstage application locally
2. Configure the Github integration
3. Leverage the `yq` command line tool to manage the Backstage application configuration files
