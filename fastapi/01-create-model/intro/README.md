# FastAPi: Create the model

This lab focuses on the creation and testing of a simple data model for FastAPI.

## Leaning objectives

It describes how to:

1. Create the database connection using [SqlAlchemy](https://www.sqlalchemy.org/)
2. Create the model of the database table using [SqlAlchemy](https://www.sqlalchemy.org/)
3. Create the schema to validate the transactions using [Pydantic](https://docs.pydantic.dev/)
4. Create a simple CRUD _(n. Create, Read, Update, Delete)_ to manage the transactions in the database table using [SqlAlchemy](https://www.sqlalchemy.org/)
5. Log and Trace database transactions using [OpenTelemetry](https://opentelemetry-python.readthedocs.io/) and [Jaeger](https://www.jaegertracing.io/)
6. Test transactions using [Pytest](https://docs.pytest.org/)
