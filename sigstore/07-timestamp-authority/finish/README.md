# Congratulations

You signed a file with a signed timestamp, and verified it without a transparency log.

## What was done

* Downloaded the certificate chain of a Timestamp Authority.
* Created a signing config and a trusted root for a private Sigstore service.
* Read and verified an RFC 3161 signed timestamp.
